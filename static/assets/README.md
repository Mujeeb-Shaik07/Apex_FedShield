# Background assets

The live login/dashboard background is a self-contained `<canvas>`
particle-network animation defined inline in `index.html` — no external
video files are required or loaded, so there's nothing to license or
place in this folder.

This directory (and the `/static` mount in `app/main.py`) is left in
place in case you want to add your own licensed static assets (a
favicon, a logo, etc.) later.
